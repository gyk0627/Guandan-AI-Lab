## 三、什么作废了、为什么

2026-11-03 确认并修改了三条规则：

1. **连对恰好 3 对（6 张）**：2 对、4 对都非法（此前实现允许 2~13 对）。

## 六、环境上的坑（都是踩过的）

| 坑 | 处理 |
|---|---|
| 系统 TEMP 在沙箱里不可写 | pytest 不要用 `tmp_path`，用仓库内 `.test_tmp`（已有 fixture） |
| 浏览器截图被沙箱挡 | Playwright 要用命名管道启动浏览器，需要放宽一次权限；`tools/ui_audit.js` 是现成的 18 项核查脚本 |
| 仓库根 9 个空目录删不掉 | `.tmp_eval_*`、`pytest-cache-files-*`，普通终端里 `Remove-Item` 即可（已写进 .gitignore） |
| PowerShell 显示中文乱码 | 比较字符串时用 ASCII 字段（如 `seed`、`level`），别看中文 |
| HTTP 长连接与 handler 实例 | 服务端状态必须写在**类**上，写 `self.xxx` 只对当次请求有效（踩过） |
| **git 不在 PATH 里**（装在 `D:\software\Git`） | 每台机器先确认：`& 'D:\software\Git\cmd\git.exe' --version`；不在此路径就查注册表 `HKLM:\SOFTWARE\GitForWindows` 的 `InstallPath` |
