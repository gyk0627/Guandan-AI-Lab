## 一句话论文

在不完全信息、四人两队合作、长视野高方差的对局中，**硬蒙特卡洛回报作为价值目标方差过大**；
我们以掼蛋为**基准环境**，给出可复现的规则引擎与监督基线，
用受控实验证明"直接套硬价值 + 搜索会变差"，并据此提出 **Soft-DMC（软目标 + 软采样）**
与**RLHF 策略校准**的路线与度量体系。

## 摘要（要点骨架）

- **问题**：不完全信息 + 团队合作 + 长视野 + 高方差（掼蛋作为基准环境）。这类博弈里，
  蒙特卡洛回报的方差极大，Deep Monte-Carlo（DMC）用硬回报回归 Q 值，容易出现
  "价值目标噪声大 → 策略过度自信 → 搜索被错误价值带偏"。
- **方法主张**：Soft-DMC = ①**软价值目标**（对回报做软化/分布化，降低方差与过拟合）
  + ②**软动作采样**（按策略分布采样而非 argmax，保留探索与多样性）；
  再叠加 ③**RLHF 策略校准**（人类成对偏好 → 奖励模型 → KL 约束下的策略校准），
  让"强策略"与"人类偏好/可解释性"对齐。
- **本文给出的实证基础**（已完成，可复现）：
  - 规则引擎与数据管线（349→**359 条测试**、逐手重放审计、发牌随机性 p=0.84）；
  - 行为克隆基线：验证一致率 **0.756**、对启发式 **51.50%**（200 局配对，CI 44.61–58.33）；
  - 价值网络：AUC **0.635**（v2 状态）→ **0.700**（v3 加入出牌历史）；
  - **两个负结果**：一步前瞻使棋力从 51.50% 降到 **26.00%**（v2 价值）、
    加入历史后反而降到 **16.50%**（v3 价值，AUC 更高）；
  - 用 `top_k=1` 对照组（51.50%，逐局与基线一致）证明不是实现问题。
- **方法学结论**：价值网络全局 AUC 0.700，但**决策内偏好准确率只有 28.81%**
  （随机 20%，策略网络对照 59.06%）——**全局 AUC 不是前瞻质量的充分指标**，
  论文应以"决策内偏好准确率"作为价值网络的可用性判据。
  这直接支撑了"必须软化价值目标"的路线选择。
- **算力刻画**：CPU 引擎是瓶颈（5.2–10 局/秒/核），4 进程 3.04×；1000 万局 ≈ 3700 核时。

## 1. 引言

- **研究问题**：不完全信息合作博弈中的价值估计与策略校准。
  为什么不完美信息 + 2v2 合作 + 长局会让 DMC 的硬回报目标失效？
- **为什么不直接上更大算力**：DanZero / DanZero+ 已用大算力 RL 在该基准上取得很强结果；
  本文关心的是**方法**（软目标、软采样、人类校准），而非再刷一次棋力。
- **贡献（按方法路线组织，不按"我们做了个游戏 AI"组织）**：
  1. **可复现基准与度量**：规则引擎、数据管线、配对评估协议（含 Wilson CI、换边控制）；
  2. **失效分析**：一步前瞻在硬价值下显著降低棋力，并给出对照组排除实现缺陷；
  3. **指标批判**：证明全局 AUC 与"可用于决策"不等价，提出决策内偏好度量；
  4. **路线设计**：Soft-DMC（软目标 + 软采样）的算法草案与评价指标
     （软动作采样已实现，软目标待实现，见 §7）；
  5. **未来工作**：RLHF 校准的数据协议（网页人机对战采集人类对局）与先导实验 E14——
     证明"单负样本的成对目标不能直接当挑牌器"，即 RLHF 必须配合策略优化。

## 2. 问题形式化

- 不完全信息扩展式博弈（EFG）：玩家集 {0,1,2,3}、队伍映射（0,2）/（1,3）、
  信息集、联合策略空间、团队效用（头游/升级数）。
- 与 POMDP 的关系：观测 = 自己的手牌 + 公开出牌历史；隐藏 = 其余三家手牌与顺序。
- **回报方差分析**：定义单局回报 R（胜负或升级数），说明其在长局合作博弈中的高方差，
  以及为什么直接回归 R 的 Q 学习（DMC）会产生高噪声目标。
- 掼蛋规则摘要（只作为基准环境的规格说明，不展开成"游戏介绍"）。

## 3. 基准环境与可复现性（数据：E00 审计）

- 规则引擎：359 条测试；300 局逐手重放零违规；比较关系 0 矛盾。
- 发牌随机性：54 种牌座位分布 p=0.84，成对数与独立模拟一致。
- 数据管线：采集 → 结构校验 → 导出（逐局重放 + 候选重算 + 三重校验），**失败即报错**。
- 这一节的作用：保证后续所有结论都建立在**可复现**的基准上（方法学要求）。

## 4. 表示与策略网络

- 候选打分范式：state tower + candidate tower，动作编码 65 维（牌面 54 + 牌型 9 + 张数 1 + 过牌 1）。
- 状态表示演进：
  - v2（198 维）：手牌、已出牌池、剩余张数、级牌、pass_count、上一手；
  - **v3（258 维）**：追加最近 6 手序列（座位 24 + 特征 24）、双方进度 2、出完人数 2、
    炸弹数 2、手牌结构 6。动机：给价值估计补上"时间维度"。
- 关键设计：只读自己手牌 + 公开信息（有测试保证不读别家牌面）。

## 5. 监督基线：行为克隆的天花板（E02）

- 40 轮、batch 64、交叉熵，最佳第 37 轮，验证一致率 **0.7562**。
- 对启发式 **51.50%**（200 局配对，CI 44.61–58.33），分边 49.0%/48.0%（无先手偏差）。
- 分桶一致率：2 候选 0.990 → 101+ 候选 0.429（候选越多越难）。
- **结论**：BC 天花板 = 老师；这解释了为什么必须转向 RL（DMC/Soft-DMC），
  也是"人类数据/偏好"不可替代的论据。

## 6. 价值目标与搜索：硬 DMC 的失效（E04–E11，本文核心实证）

### 6.1 价值目标的性质

- 目标选择：单局胜负（`team_win`）与升级数（`level_up`）都是**稀疏、高方差**回报。
- 价值网络（state → P(本队头游)）的 AUC：v2 状态 **0.635**、v3 状态 **0.700**。
- 数据量缩放（E07）：300→5000 局 AUC 0.549→0.635，边际收益低；
  正则化扫描（E09）全负；6000 局混合只到 0.6426（E10）。

### 6.2 硬价值 + 一步前瞻 = 显著变差

| 策略 | 胜率（200 局配对） |
|---|---:|
| BC 基线（v2 状态） | 51.50% |
| 前瞻 top_k=3 | 34.50% |
| 前瞻 top_k=5 | 26.00% |
| 前瞻 + 价值差门槛 0.15 | 42.00% |
| 前瞻 vs BC 直接对打 | 24.50% |
| **对照组 top_k=1（不覆盖）** | **51.50%，逐局与基线一致** |

### 6.3 更强的价值网络让搜索更糟（E11）

| 指标 | v2 状态 | v3 状态 |
|---|---:|---:|
| 价值 AUC | 0.6351 | **0.6997** |
| BC 胜率 | 51.50% | 53.00% |
| 一步前瞻（top5） | 26.00% | **16.50%** |

### 6.4 解释（直接支撑 Soft-DMC 的动机）

1. **指标错位（已实测，E13）**：价值网络全局 AUC 0.700，但在**同一局面**里
   把老师动作排第一的比例只有 **28.81%**（K=4，随机基线 20%）；二选一时 **55.14%**
   （随机 50%）。同一测试下策略网络是 **59.06%**（证明工具没问题）。
   ——**价值网络几乎没有决策内分辨力**，这正是前瞻失败的直接原因。
2. **分布外自信错误**：价值网络在老师分布上训练，前瞻推到分布外；
   网络越拟合训练分布，分布外错误越"硬"（0.635 时错得软、0.700 时错得硬）。
3. **硬目标放大噪声**：稀疏高方差回报让价值网络在"接近的候选"之间缺乏分辨力，
   于是"裁决"等于注入噪声——这正是需要**软价值目标**的地方。

## 7. 方法一：Soft-DMC（软深度蒙特卡洛）

> 状态：**软动作采样已实现**（`players/sampling.py`：温度 softmax 采样 + ε-greedy）；
> **软价值目标尚未实现**，本节给出设计。

### 7.1 与硬 DMC 的区别

| 维度 | 硬 DMC（DouZero 系） | Soft-DMC（本文主张） |
|---|---|---|
| 价值目标 | 单局硬回报 Q(s,a) | 经软化的期望回报 / 分布化回报（soft target） |
| 动作选择 | argmax 或 ε-greedy | 温度 softmax 采样（已实现） |
| 不确定性 | 不建模 | 用分布头或温度显式建模 |
| 搜索用法 | 通常不用搜索 | 只在**决策内偏好**可靠时启用前瞻 |

### 7.2 软目标的具体形式（待实现）

- **已试且不足（E15）**：只把标签换成 `0.5×胜负 + 0.5×升级数/3` 的软标签，
  验证 AUC 0.6954（硬标签 0.6997）、决策内偏好 29.18%（硬标签 28.81%）——**没有效果**。
  说明缺口不在标签形状，而在**缺少兄弟动作之间的比较信号**。
- **兄弟对监督（推荐实现）**：对同一决策点的不同候选各自模拟一步，得到相邻状态，
  用"哪一步之后更好"构造训练对，直接训练**相邻状态比较**，而不是整局回报回归。
- **分布化价值**：预测回报分布 p(R|s,a)（分类头 / 分位数），用分布间的 soft 比较替代点估计；
- **决策内偏好训练**：用成对比较（选中动作 vs 其它候选）构造目标，
  直接优化"同一局面下选对的概率"，而非全局 AUC；
- **预期收益**：降低价值目标方差 → 候选间分辨力提升 → 前瞻不再注入噪声。

### 7.3 评价协议

- 配对对抗（同种子换边）+ Wilson CI（已实现：`tools/eval_policies.py`）；
- **新增指标：决策内偏好准确率**（老师动作 vs 随机/次优动作）；
- 与硬 DMC 基线、BC 基线三方对照。

## 8. 方法二：RLHF 策略校准（**未来工作，暂不实现**）

### 8.1 问题：强策略 ≠ 符合人类偏好

- 自对弈策略追求胜率，但人类偏好还包括：可解释的牌路、不抛弃队友、
  不确定时保守、不"机械重复"等。
- 人类反馈可作为**校准信号**，把策略分布拉向"人类认可"的区域。

### 8.2 协议（拟）

1. **偏好数据采集**：同一局面给出两个候选打法（来自不同策略/温度），人类选更认可的一个；
   设计界面（已有 HTML 人机对战界面可扩展为"对比投票"）；
2. **奖励模型**：由 (s, a) 偏好对训练，输出可解释的偏好分数；
3. **策略校准**：在 DMC/Soft-DMC 的策略更新中加入奖励项与 KL 约束
   （防止策略崩坏、保持棋力）；
4. **校准度量**：偏好一致率、与人类选择的 KL、胜率保持度（校准不应显著降低棋力）。

### 8.3 预期与风险

- 预期：在保持胜率的前提下提升偏好一致率；
- 风险：人类偏好数据的噪声与规模；奖励模型过优化（需要 KL 与早停）。

### 8.4 先导实验的教训（E14，已做）

在采人类数据之前，我们先用**启发式老师冒充人类**做了成对偏好训练（难负样本，
同牌型同张数）。结果：

| 指标 | 行为克隆（softmax 全候选） | 成对比较（单负样本） |
|---|---:|---:|
| 决策内排第一 | **0.8200** | 0.7462 |
| 对启发式胜率 | **53.00%** | 29.00% |
| 对行为克隆胜率 | — | 20.50% |

**结论**：**单负样本的成对目标学不到全局排序**，直接用奖励模型对候选取 argmax 会显著变弱。
这从反面确定了 RLHF 的正确用法：

1. 奖励模型只负责**给轨迹/动作打偏好分**，不替代策略网络做动作选择；
2. 必须配合**策略优化**（PPO 类）与 **KL 约束**，让策略在保持棋力的前提下向偏好靠拢；
3. 评价要同时看**胜率保持度**与**偏好一致率**，不能只看其中一项。

## 审稿人可能问的

1. **为什么不和人类高手比棋力？** —— 本文目标是方法（软目标 + 校准），不是 SOTA；
   DanZero 系已证明大算力 RL 在该基准上可行。
2. **AUC 0.70 还不算高，你的负结果是否只是"训练不够"？** —— E07 缩放曲线显示边际收益低，
   E09 正则化全负，E11 显示 AUC 提升反而更差；三点共同说明是**目标与指标**的问题。
3. **Soft-DMC 的"软"具体指什么？** —— 见 §7.1/§7.2（软目标 + 软采样 + 决策内偏好目标），
   与硬 DMC 的差别是显式的。
4. **RLHF 数据从哪来、怎么防过优化？** —— 见 §8.2（成对偏好 + 奖励模型 + KL 约束 + 早停）。
5. **样本量与显著性**：所有胜率均为 200 局配对，CI 约 ±6–7 个百分点；
   51.5% vs 26% 远超区间；AUC 差异 0.065 属中等效应，需在论文中给出重复实验。
